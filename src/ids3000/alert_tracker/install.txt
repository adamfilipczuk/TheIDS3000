Python Watchdog + Pygtail Installation
====================================

Requirements:
-------------
- Python 3.6 or higher
- pip package manager

Install required libraries:
---------------------------
pip install watchdog pygtail

(Optional) Using a virtual environment:
----------------------------------------
python -m venv venv

Activate virtual environment:
- Linux/macOS:
  source venv/bin/activate
- Windows:
  venv\Scripts\activate

Install libraries inside virtual environment:
---------------------------------------------
pip install watchdog pygtail

Notes:
------
This setup allows you to use Watchdog for file system monitoring and Pygtail for reading log files incrementally.
